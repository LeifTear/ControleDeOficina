**1 Descrição do Projeto**

O Sistema de Gerenciamento de Oficina Mecânica é uma aplicação desenvolvida na linguagem Java com execução via terminal (console). O objetivo do sistema é auxiliar no gerenciamento das informações de clientes e veículos cadastrados em uma oficina mecânica.

A aplicação permite realizar operações de cadastro, consulta, edição e exclusão de registros, seguindo o conceito de CRUD (Create, Read, Update e Delete). Os dados são armazenados temporariamente em estruturas do tipo ArrayList e podem ser persistidos em arquivos texto (.txt), permitindo que as informações sejam recuperadas mesmo após o encerramento do programa.

O projeto foi desenvolvido utilizando os conceitos de Programação Orientada a Objetos (POO), promovendo a organização do código em classes específicas para cada responsabilidade do sistema.

**2 Como Executar o Sistema**

Para executar o sistema, é necessário possuir o Java Development Kit (JDK) instalado na máquina.

Passos para execução:
Abrir o projeto em uma IDE compatível com Java, como:
IntelliJ IDEA;
NetBeans;
Eclipse.
Compilar os arquivos do projeto.
Executar a classe principal responsável pelo início da aplicação.
O sistema apresentará um menu interativo no terminal contendo as opções disponíveis.
O usuário poderá navegar pelas funcionalidades digitando o número correspondente à opção desejada.
Os dados cadastrados poderão ser armazenados em arquivo texto para posterior recuperação.
Requisitos para execução
Java JDK 17 ou superior (ou a versão utilizada no desenvolvimento);
Sistema operacional Windows, Linux ou macOS;
Terminal ou IDE compatível com Java.
